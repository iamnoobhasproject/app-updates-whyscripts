BurnedWolf 4.3.0

BurnedCord reliability update:
- Fixed all BurnedCord Copy buttons in the Electron desktop window using the native clipboard bridge.
- Added queued/retried realtime signaling so SDP/ICE is not silently lost during short reconnects.
- Improved automatic ICE restart behavior.
- Added automatic TURN relay fallback through the chat backend for restrictive NAT/firewall networks.
- Direct peer-to-peer remains preferred; TURN is used only when ICE needs a relay path.
