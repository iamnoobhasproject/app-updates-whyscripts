BurnedWolf 4.4.0

- Fixed BurnedCord microphone/camera permission handling in the Electron desktop window.
- Fixed remote voice playback startup in the desktop client.
- Reworked WebRTC signaling for the shared-hosting polling transport: SDP now waits briefly for ICE gathering instead of flooding the server with individual candidate requests.
- Reduced in-room signaling polling latency.
- Added Windows system-audio capture when sharing a screen or application window.
- Added separate shared-screen audio controls: right-click a shared screen to adjust its volume (0-200%) or mute it locally.
- Preserved native Electron clipboard support for all Copy actions.
