BurnedWolf 4.6.1 — Core Migration Bridge

- Adds a second Core/Electron runtime update lane.
- Adds an Electron compatibility guard for future app.asar updates.
- Splits the application update channel so legacy Electron 26 clients stay safe forever.
- Existing pre-bridge clients use version.json + update.zip (freeze at 4.6.1).
- 4.6.1+ clients use version-v2.json + app-v2.zip.
- Core updates use core-version.json and a full GitHub Release installer.
- This bridge still runs Electron 26.6.10.
