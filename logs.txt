BurnedWolf 4.5.0

BurnedCord desktop media reliability update.

- BurnedCord now renders from the same HTTPS origin as the working web version instead of file://.
- Desktop voice/API traffic uses the browser-native same-origin path again.
- Remote audio playback now uses direct HTMLMediaElement playback instead of a fragile WebAudio relay chain.
- Native Electron clipboard integration remains available for all Copy actions.
- Microphone/camera/display permissions are restricted to the official chat.whyscripts.com origin.
- Screen-share source picker and system-audio controls from 4.4 are preserved.
